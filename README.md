# Lab 3 — Prompt Engineering

This repository contains six Python exercises completed as part of Lab 3 — Prompt Engineering.

## Exercises

### Exercise 1 — Doctor Summary Generator
Creates a structured medical consultation summary with Symptoms, Diagnosis, and Recommendation sections.

### Exercise 2 — Review Classifier
Classifies customer reviews into POSITIVE, NEGATIVE, MIXED, NEUTRAL, or UNCLEAR categories.

### Exercise 3 — Resume Field Extractor
Extracts requested information from resume text and formats the results as JSON.

### Exercise 4 — Customer Support Reply Generator
Generates concise customer support replies while checking a specified maximum word count.

### Exercise 5 — Multi-language Translator
Demonstrates translations for supported sample sentences using formal, neutral, and informal styles.

### Exercise 6 — Iterative Content Refiner
Revises a draft over three rounds to address a specified writing issue.

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run an exercise using Python.

Example:

```bash
python exercise1_doctor_summary.py
```

Replace the filename with the exercise you want to run.

## Implementation Notes

The current versions use basic rules and predefined examples. They do not make live AI API calls. The translator supports only the sample sentences included in its dictionary.

## Security

Never upload API keys, passwords, or other secrets to GitHub. Keep local environment files excluded through `.gitignore`.
